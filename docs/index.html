Design Principles — v0.2
1
Tool selection must be explainable
AgentHallu 2026
Research basis
Tool-Use Hallucination is the hardest to detect — even GPT-5 achieves only 11.6% accuracy. A wrong tool selection contaminates every subsequent step.
Practice
Measure confidence before tool call. If below threshold, request user confirmation or stop. Always log selection rationale in StepTrace.
2
Context boundaries must be explicitly designed
TrajAD 2026
Research basis
Agents blindly pursue goals while ignoring process rationality. Context contamination spreads silently — it doesn't surface until the final answer.
Practice
Separate context into explicit slots: system prompt (fixed), session facts (verified), current input (per-turn), history (summarized).
3
Retrieval quality must be validated before generation
DeepHalluBench 2026
Research basis
Retrieval and Planning hallucinations account for over half of all failures. Poor retrieval propagates hallucinations into the planning stage.
Practice
Gate retrieval with relevance score threshold. If below threshold, return "no relevant information found" — do not proceed to generation.
4
Every step must be independently evaluable
HTC + TRACE 2026
Research basis
The "high-score illusion": even correct final answers may rest on flawed reasoning. Last-step confidence alone misses intermediate failures.
Practice
Log every step as a StepTrace struct with input, output, confidence, reasoning, and diagnostic signals. No LLM call without a trace.
5
When uncertain, stop and explain — never guess
HTC 2026
Research basis
Last-step confidence 0.973 — but the answer was wrong. Full trajectory confidence should have been 0.052. Confident wrong answers are a design failure.
Practice
3-tier confidence response: Confident (≥0.80) / Hedged (≥0.50) / Uncertain (<0.50 → stop + explain + suggest alternative).
Evaluation Layers — 3-tier hierarchical diagnosis
Step-level Eval
Independent evaluation of each decision step. Tool selection, context usage, intermediate reasoning quality.
